## How to Update the Website

### Option A — GitHub (simple edits)
1. Open the file you want to edit in this repo
2. Click the **pencil/edit icon** ✏️
3. Make your changes
4. Click **"Commit changes"**
5. Netlify auto-deploys within ~30 seconds ✅

### Option B — Local (recommended for multiple file changes)
```bash
git add .
git commit -m "Your update message here"
git push
```
Netlify picks it up automatically after the push.
